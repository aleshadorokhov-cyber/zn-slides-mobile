# Конструктор презентаций для телефона

Мобильная версия конструктора презентаций (корпоративный шаблон). Работает в браузере iPhone и Android,
документы обрабатываются в самом телефоне.

**Как установить:** откройте адрес сайта этого репозитория на iPhone в Safari и нажмите
«Поделиться» → «На экран „Домой“». На Android откройте в Chrome: меню ⋮ → «Установить приложение».
После первого запуска (около 55 МБ) конструктор работает без компьютера и без интернета.

В конструкторе есть библиотека из 158 фото с Викисклада (папка `photos/`) под открытыми лицензиями.
Автор и лицензия каждого снимка — в `photos/CREDITS.txt`; при выборе фото автор сам пишется в заметки слайда.

Версия 1.8 повторяет Windows-версию 1.8: личный кабинет «👤» со списком своих презентаций и профилем
(на телефоне без пароля, у каждого телефона свой кабинет), автосохранение работы при закрытии вкладки,
база ключевых слов по 16 темам с пополнением через локальную модель ИИ и обучение из 8 шагов при первом открытии.
Из 1.7.2: фраза или число открываются в документе-источнике с выделением цветом. Из 1.7.1: окно «🎨 Вид» с семью темами
и размером текста, крестик закрытия во всех окнах, а также всё из 1.7: проверка презентации («✔ Проверить»), словарь Компании,
версии для разных слушателей, библиотека материалов и «План по образцу», поиск готовых фраз, свои слайды из PowerPoint,
эффекты к фото, значки пунктов и их подложка. Только в Windows-версии: автопилот, поиск и установка моделей ИИ,
3D-модели, проверка готового файла по картинкам слайдов.

Сторонние компоненты и их лицензии: `vendor/NOTICES.md`.
